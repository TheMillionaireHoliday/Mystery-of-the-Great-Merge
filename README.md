## Game Jam Project

Game made in 72 hours for **CtrlShiftCreate** Game Jam hosted by ITAM MISIS.

Includes fully original music and graphics.

Made in a team of 5 - including 2 artists, 1 composter, 1 composer/level designer and me (game designer / sole programmer).

Uses pre-made character controller.
